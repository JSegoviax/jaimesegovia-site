Process

How I build

I'm a product person, not an engineer. I work by directing AI tools: Cursor and Claude Code for building, and a set of agents for the product work around it.

The rule I keep, at work and on side projects, is that agents do the work and a person makes the call. Every change gets checked, risky steps wait for approval, and nothing touches a live system until it has run in a test.

ShapeWrite the spec until the decisions are made.
BuildAgents write and review the code.
PlayTest it like a player, then iterate.
